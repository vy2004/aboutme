# Nguyen Quoc Vy Portfolio

Static personal portfolio site built with HTML, CSS, and a small JavaScript file for the gallery and ripple effects.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Push the contents of this folder to the `main` branch.
3. In GitHub, open `Settings` > `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`.
6. Save. GitHub Pages will publish the site at your repository URL.

## Local run

Open `index.html` in a browser.
